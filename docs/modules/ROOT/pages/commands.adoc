= Commands
:description: Every findable command, flag and exit code.

[cols="1,3"]
|===
| Command | What it does

| `audit` | Every finding, worst first, with all its pages and a fix. Read-only.
| `plan` | The files `apply` would write, and every finding as `MANUAL`. The default.
| `apply [FILE]` | Write the files, then plan again to verify. With a saved plan, exactly those.
| `status` | Pages and finding counts per target.
| `validate` | Check the config offline.
| `doctor` | Install health: binary, config, each target.
| `ui` | The admin page.
| `mcp` | The MCP server on standard input and output.
| `version` | The version.
|===

== Flags

[cols="1,3"]
|===
| `-config FILE` | Config file, or `-` for standard input.
| `-target NAME` | Limit to this target; repeat for several.
| `-out FILE` | `plan`: save the plan for `apply FILE`.
| `-json` | `audit`, `plan`, `status` and `doctor`: machine-readable.
| `-exit-code` | `audit`: exit 2 on an error finding. `plan`: exit 2 for changes, 3 for manual-only.
| `-yes` | `apply`: skip the confirmation prompt for deletions. The `site` provider never deletes.
|===

== Exit codes

[cols="1,3"]
|===
| `0` | Nothing to do, or the apply converged and was verified.
| `1` | Something failed.
| `2` | With `-exit-code`: changes are outstanding, or the audit found an error.
| `3` | With `-exit-code`: nothing left but `MANUAL` items.
|===

== In CI

[source,yaml]
----
- run: npm run build
- run: findable audit -exit-code
----
