# Roadmap

## Next

- A provider for the system this tool exists for.
- Redirect chains longer than one hop, and canonicals that point at a page
  answering 3xx, 4xx or 5xx, as seonaut reports them.
- Experience and authorship signals: a named author and a date on articles,
  an about page that names the people.
- `llms-full.txt`: the full text of the listed pages, next to llms.txt.
- Answer tracking: ask AI search engines each of `queries:` and record whether
  the answer cites the site.
- Search Console and Bing Webmaster data in `status`: clicks and position for
  each of `queries:`.

## Not planned

- Applying from an agent without a person's yes to the plan.
- A plan that performs writes.
