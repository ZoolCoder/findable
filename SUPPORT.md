# Getting help

findable is maintained in spare time. Pick the channel that fits so
questions get an answer and bugs get fixed.

| You want to | Go to |
|---|---|
| Learn how something works | The [manual](https://zoolcoder.github.io/findable/), starting with [getting started](https://zoolcoder.github.io/findable/findable/getting-started.html) |
| Report a bug or a skill that misbehaved | [New issue](https://github.com/ZoolCoder/findable/issues/new/choose), with `findable doctor` output |
| Ask for a provider or a feature | [Feature request](https://github.com/ZoolCoder/findable/issues/new/choose) |
| Report a security problem | [SECURITY.md](SECURITY.md), never a public issue |
| Contribute code, docs or a skill | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you ask

1. Run `findable doctor`. It names the broken step.
2. Run `findable version` and check the [releases page](https://github.com/ZoolCoder/findable/releases) for a newer one.
3. Search the existing issues.

## What to include

- `findable doctor` and `findable version` output.
- Platform, the providers involved, and the agent if one was used.
- The smallest config that reproduces it, with real paths replaced by placeholders.

## Response time

Issues are read within a week. There is no paid support and no SLA; fixes
land in the next release.
